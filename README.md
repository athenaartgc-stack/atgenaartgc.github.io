# ดูแลพอร์ต AthenaART

ลิงก์ลูกค้า: https://athenaartgc-stack.github.io/atgenaartgc.github.io/

## อัปเดตคิว
แก้ `queue.json` โดยคงรายการไว้ 5 ช่อง แต่ละช่องใช้ค่าใดค่าหนึ่ง:
- `empty` = ว่าง
- `wip` = กำลังวาด
- `process` = ดำเนินการ
- `final` = รอคอนเฟิร์ม

จากนั้นเปิดโฟลเดอร์เว็บนี้ใน GitHub Desktop → ตรวจ Changes → Commit to main → Push origin
รอ GitHub Pages เผยแพร่ แล้วเปิดลิงก์ลูกค้าเพื่อตรวจอีกครั้ง
ลูกค้าทุกคนอ่านข้อมูลจากไฟล์กลางเดียวกัน ปุ่มบันทึกเฉพาะเครื่องถูกนำออกแล้ว
คิวเริ่มต้นคงค่าเดิมของเว็บไว้ โปรดยืนยันคิวจริงก่อนรับงาน

## เพิ่มผลงาน
ภาพต้นฉบับยังอยู่ในโฟลเดอร์เดิมครบ ภาพสำหรับเว็บอยู่ใน `assets/web/`
เพิ่มภาพสำหรับเว็บและแก้รายการ `ILLUS` (ภาพส่วนตัว), `COMM` (คอมมิชชั่น)
หรือ `PROJECTS` (โปรเจกต์) ใน `index.html` แล้ว Commit และ Push
ใช้ WebP ที่กว้างประมาณ 1920–2200 พิกเซล และภาพตัวอย่างกว้างประมาณ 600 พิกเซล
ตรวจว่าชื่อไฟล์และตัวพิมพ์ใหญ่เล็กตรงกัน หลีกเลี่ยงการส่งไฟล์ต้นฉบับขนาดใหญ่มาแสดงเป็นภาพตัวอย่าง
รายชื่อภาพที่ยังไม่มีไฟล์จริงเก็บใน `maintenance/missing-images.txt` เพื่อเติมภายหลัง

## ลิงก์เดิม
คงชื่อบัญชี ชื่อ repository และการเปิด GitHub Pages เพื่อรักษาลิงก์เดิม
การปิดคอมไม่ทำให้เว็บหยุดออนไลน์

## หมายเหตุสำเนา
การแก้ครั้งนี้ทำในสำเนาใหม่จาก GitHub โฟลเดอร์เดิมในไดรฟ์ D ยังมี merge ค้าง
อย่า Push จากโฟลเดอร์เดิมจนกว่าจะจัดการสถานะนั้น ให้ใช้สำเนาใหม่นี้สำหรับการอัปเดตต่อไป
